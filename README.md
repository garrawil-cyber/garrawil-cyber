## 🚀 Proyectos Destacados

### 🏫 Sistema de Control de Asistencia Docente
Ecosistema completo para el registro de asistencia en tiempo real mediante códigos QR dinámicos. Incluye App Móvil, API REST, Panel Admin y Kiosko.
- **Backend:** [asistencia-api](https://github.com/garrawil-cyber/asistencia-api) *(PHP puro MVC + MySQL + JWT)*
- **App Móvil:** [AsistenciaDocentes](https://github.com/garrawil-cyber/AsistenciaDocentes) *(Kotlin + Jetpack Compose + CameraX)*
- **Características:** Autenticación JWT, QR dinámico (anti-fraude), Reportes Excel/PDF, Módulo de Backups.

### 🚌 [Sistema de Transporte](https://github.com/garrawil-cyber/Sistema_transporte)
Sistema integral para empresa de transporte de pasajeros, encomiendas y giros.
- **Stack:** PHP + MySQL + Bootstrap 5
- **Módulos:** Ventas, Encomiendas, Giros, Viajes, Caja, Auditoría.

### 📦 [Sistema de Inventario](https://github.com/garrawil-cyber/Inventario)
Sistema web completo para gestión de inventario, productos, ventas y ubicaciones.
- **Stack:** PHP + MySQL + Bootstrap 5
- **Módulos:** Productos, Ventas, Ubicaciones, Usuarios, Reportes.
